# Interface — referência visual do GamepadBridge

Esta pasta contém arquivos de referência enviados separadamente para orientar o desenvolvimento de uma nova interface por outra IA.

## Conteúdo
- `app.zip`: pacote original enviado, com os arquivos Java e XML da interface/teste do controle.

## Instruções importantes
- Use os arquivos apenas como BASE/REFERÊNCIA para estudar o desenho do controle, os estados visuais, os analógicos, os gatilhos e a tela de teste.
- Desenvolva a nova interface separadamente.
- NÃO copie esta pasta para dentro do código de produção automaticamente.
- NÃO substitua, mova, renomeie ou edite arquivos existentes do GamepadBridge.
- Esta pasta é isolada e não faz parte do fluxo de compilação do aplicativo.
